# Tiled Map Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the randomly generated circular islands with the hand-authored Tiled map at `public/assets/map/arena.tmj`, rendered as its 5 layers and collided via layer 3 only.

**Architecture:** A pure runtime parser turns the `.tmj` + `teste.tsx` into a `TiledMapDef`; `buildArena` derives the sim's `Arena` (bounds, collision grid, player spawn) from it; `ArenaView` draws one sprite per non-empty cell in the 5 layer containers; the map+tiles load through a cache-once asset shell wired into the existing loading/error/Retry flow.

**Tech Stack:** TypeScript strict, PixiJS v8 (`Assets`, `Sprite`, `Container`), Vite (serves `public/`), Playwright chromium for throwaway browser checks. No test framework — verification is throwaway Node scripts (bare-tsc compile) plus a throwaway Playwright harness, per repo convention.

**Spec:** `docs/superpowers/specs/2026-10-10-tiled-map-design.md`

## Review Focus

Each line is a failure mode a reasonable person would hit; the owning task carries the test that pins it.

1. **Flip-flag math (H/V/D on real cells, including flips on small crew images)** — wrong composition mirrors decorations visibly wrong. → Task 4 browser test samples the three flipped cells' screen regions for non-background pixels, plus a Node identity check of the transform composition helper (Task 4).
2. **Crew bottom-left alignment** — top-left placement drops crew sprites half a cell up, floating. → Task 4 browser test: a crew gid's pixels sit in the bottom half of its cell rect.
3. **Spawn on water only near world edges/corners** — the camera-relative ring ∩ arena shrinks at corners; spawn could pick land or give up too often. → Task 3 Node check: 100 seeds at center (≥95 non-null, all invariants) and each corner (≥50 non-null, all invariants).
4. **Collision push-out degenerate case (ship center inside a solid cell)** — normal from a zero-distance center is undefined; a naive push teleports or NaNs. → Task 3 Node check drives a ship center INTO a known solid cell and asserts a finite, outside result, idempotent on re-run.
5. **Strict-Mode double mount of the map loader** — two fetches/textures double-loaded, or cleanup destroys shared textures. → Task 4 browser test counts `/assets/map/arena.tmj` fetches via route interception (exactly 1) and confirms the match still renders after the double mount.
